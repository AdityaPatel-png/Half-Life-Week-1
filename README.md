Keyboard But better
My project is a mechanical gaming keyboard combined with a doc and a touchpad. 
Essentially, it has some keys from a standard keyboard (wasd, num keys, ctrl, c & v) that will fulfill most need from an external piece.
It also will connect with a touchpad which will give a better experience if it is used when connected to a smartphone or tablet.
Finally, It will have a MicroSD slot and a USB A and C port (USB A is power only) because external storage is cool and you can never have too too many USBs.
The brain of my PCB is a Raspberry Pi Pico.
